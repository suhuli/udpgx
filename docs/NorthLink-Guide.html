NorthLink
使用指南 / 0.1.0 / WINDOWS X64
PRIVATE SERVICES. DIRECT CONNECTION.

两端之间，
直接相连。

让客户端通过本地端口，访问另一台 Win10 上的网站、远程桌面和其他 TCP 服务。Redis 只负责联系双方，业务不绕经中转。

ICE + QUIC中文界面托盘运行
在网站 / 远程桌面所在的电脑运行NorthLink.Provider.exe
在需要访问服务的电脑运行NorthLink.Client.exe

完整解压后运行。已包含 .NET 桌面运行时，不要单独复制 EXE 或删除同目录 DLL。

先了解边界：这是首版。已完成 Windows 构建和开发环境本地链路验证，但尚未在真实 Win10 桌面、服务管理器、远程桌面或你的跨网 NAT 环境验证。遇到严格 NAT / 封 UDP，直连可能失败；不会回退到 Redis、TURN 或其他中转。
01 / START

三步配置，开始连接

01

两端填写同一信令配置

在“连接配置”填写 Redis 主机、端口、用户名（可留空）、密码和 DB。连接组也保持一致，保存后启动两端。主机不带 redis://。

02

提供端发布 TCP 服务

默认已有网站 80 和远程桌面 3389，目标均为 127.0.0.1。也可添加其他本机或内网目标。确认服务本来就在运行，再保存并应用。

03

客户端添加端口映射

进入“端口映射”，选择在线提供端和服务，添加映射并保存。等待“已直连”，然后使用对应的本地端口访问。

访问网站

http://127.0.0.1:18080

需要固定 Host 的网站或绝对重定向，可能需要调整网站绑定；NorthLink 不改写 HTTP。

访问远程桌面

mstsc → 127.0.0.1:13389

使用提供端的 Windows 凭据。第一版走 TCP，不改变 Win10 版本和多用户会话限制。

02 / STUN

已替换的默认节点

stun:stun.hitv.com:3478
stun:stun.miwifi.com:3478
stun:stun.xten.com:3478
stun:stun.voip.aebc.com:3478
首项为 stun.hitv.com。地址和端口都可修改；多个节点并行收集候选，ICE 决定实际可用路径。上述公共节点的实时状态与具体端口尚未验证。

网络需要允许什么？

  • 两端均能访问同一 Redis 5.0+ 实例，且允许 Streams、SCAN 等程序所需命令。
  • 允许访问 STUN，以及对端动态 UDP 地址 / 端口。只开放 UDP 3478 不足够。
  • “放行程序 UDP”可添加 Windows 防火墙规则，需要管理员确认；不能改变企业网络策略。
  • 已有直连通常不受 Redis / STUN 暂时离线影响；新打洞仍依赖信令和地址发现。
03 / BACKGROUND

保持后台运行

普通托盘模式

  • 点击窗口 X，只隐藏到右下角托盘。
  • 双击托盘恢复；右键可配置、启动、停止、退出。
  • “登录 Windows 时启动”与“软件启动后自动连接”是独立选项，按需同时勾选。
  • 配置按当前 Windows 用户保存，导出文件包含 Redis 密码，请妥善保管。

提供端无人值守

  • 在“连接配置”中安装 Windows 服务，需要管理员权限。
  • 重启后、尚未登录也可尝试上线；初始 Redis 不可用时会重试。
  • 安装后不要移动程序目录。移动或升级前，先移除服务。
  • 托盘可选“退出界面（保留无人值守服务）”；“停止并退出”则停止核心。
04 / DIAGNOSE

先分清，卡在哪一步

观察到的状态优先检查
Redis 连接失败主机、密码、ACL、TLS、DB。信令要使用 Redis 5.0+ 的 XADD / XREAD，不只是 PING。
看不到提供端两端连接组和 Redis DB 是否相同，提供端是否启动；在线列表约 5 秒刷新。
没有 STUN 映射日志中的候选数量、STUN 的实际端口、DNS 与 UDP 可达性。仍可尝试内网 / IPv6 直连。
信令在线，无法直连NAT、UDP 限制和防火墙。多个 STUN 不等于保证打洞成功，也不会自动中转。
已直连，目标访问失败提供端的目标服务是否启动，目标 IP / 端口和 Windows 远程桌面设置是否正确。
本地监听失败客户端端口被占用，或本地绑定 IP 不存在。更换端口后保存并应用。
配置与日志：%LOCALAPPDATA%\NorthLink\provider 或 client。界面保留最近 250 条事件，磁盘日志轮转。保存并应用配置会重建连接，已断 TCP 会话不能无感续接。
本版提供 TCP 映射、托盘、配置和可选服务模式；不含原生业务 UDP、多用户权限系统、TURN、中转兜底或所有 NAT 必达保证。完整说明见同目录 README.md。
